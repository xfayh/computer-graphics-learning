## 建议学习节奏（6–8 周）
| 周次 | 内容 | 实践产出 |
|---|---|---|
| 1 | 标量、向量空间、线性映射 | Vec2/Vec3 |
| 2 | 点积、叉积、投影、法线 | 几何运算测试 |
| 3 | 矩阵、行列式、逆矩阵 | Mat3/Mat4 |
| 4 | 坐标系、齐次坐标、变换链 | Transform demo |
| 5 | 三角学与旋转 | 旋转实验 |
| 6 | 微积分与梯度 | 高度场法线 |
| 7 | 概率与 Monte Carlo | 随机采样实验 |
| 8 | 浮点误差与综合验收 | 数学库 v1 |

## 阶段验收
- 独立实现 Vec2/Vec3/Vec4、Mat3/Mat4。
- 推导点积、叉积、矩阵乘法和齐次变换。
- 解释坐标系手性、矩阵布局、向量乘法侧的差异。
- 单元测试覆盖正常、退化和数值边界情况。
