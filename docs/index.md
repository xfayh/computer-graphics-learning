# Computer Graphics Learning

本知识库沿着 **数学原理 → 几何与渲染算法 → GPU 与 Shader → 图形 API → 渲染引擎** 的主线学习。

## 12 个阶段
1. 数学基础与图形学预备知识
2. 计算机图形学基础原理
3. 三维几何与空间变换
4. 光栅化渲染原理
5. 光照、材质与纹理
6. GPU 架构与 Shader 编程
7. OpenGL
8. DirectX 11 / DirectX 12
9. Vulkan、Metal 与 WebGPU
10. 高级实时渲染
11. 光线追踪与路径追踪
12. 渲染引擎架构与工程实践

每个阶段包含数学推导、原理图、算法流程、C++ 实现、API 映射、测试和实践项目。
